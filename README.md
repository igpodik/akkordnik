# Аккордник

Тренажёр боя и смены аккордов для начинающих гитаристов. Для каждой песни показывает текущий и следующий аккорд с аппликатурой, анимированную руку с направлением удара, ленту боя со счётом и карту песни. Звук гитары и метроном синтезируются прямо в браузере, поэтому никаких записей в проекте нет.

Каждая песня это текстовый файл в папке `songs`. Добавил файл, и после сборки у песни появляется своя страница.

## Запуск у себя

Нужен Node.js 20 или новее.

```
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`. Тесты парсера запускаются командой `npm test`.

## Как добавить песню

Проще всего через редактор на самом сайте: кнопка «Добавить песню» на главной. Пишешь текст слева, справа сразу работает плеер, ошибки показываются с номером строки. Потом копируешь текст, сохраняешь в `songs/имя.song` (имя редактор подскажет) и делаешь коммит.

## Формат файла .song

```
title: Пачка сигарет
artist: Кино
tempo: 87
start: 60
strum: D U M U

[Вступление]
Em:4 Am:4 C:4 D:4 x2

[Куплет 1]
Em:4 Am:4 C:4 D:4 x4

[Припев] = Куплет 1
[Куплет 2] = Куплет 1
[Припев]
```

Сначала идут поля, затем разделы.

Поля:

1. `title` название, обязательно.
2. `artist` исполнитель.
3. `tempo` темп оригинала в ударах в минуту, обязательно. Это верхний предел ползунка.
4. `start` темп, с которого открывается страница. Если не указан, берётся чуть больше половины оригинала.
5. `tempo-note` пояснение под ползунком темпа.
6. `strum` бой на 4 или 8 восьмых: `D` вниз, `U` вверх, `M` глушение, `-` пауза. Четыре знака повторяются дважды на такт.
7. `easy-strum` бой для режима «Только вниз», по умолчанию удар вниз на каждую долю.
8. `strum-text` словесное описание боя, оно идёт первым советом.
9. `easy-chords` замены для кнопки «Лёгкие аккорды», например `Bm=G, F=Fmaj7`.
10. `easy-text` пояснение к лёгкому режиму.
11. `pairs` смены для тренировки, например `Em-Bm, C-D`. Если не указаны, берутся первые смены песни.
12. `tip` совет. Можно писать сколько угодно строк `tip`.

Разделы:

1. Заголовок раздела в квадратных скобках: `[Куплет 1]`.
2. Каждая следующая строка это строка песни: аккорды через пробел. Число после двоеточия это длительность в долях: `Em:2`. Без числа аккорд длится 4 доли, то есть такт.
3. `x3` в конце строки повторяет её три раза.
4. `[Куплет 2] = Куплет 1` копирует аккорды другого раздела.
5. Пустой раздел с тем же именем, что уже был выше, повторяет его: второй `[Припев]` без строк играет первый припев.
6. Комментарии пишутся после `//`.
7. `H` можно писать вместо `B`: `Hm` превратится в `Bm`.

Аккорд должен быть в словаре аппликатур `src/chords.js`. Если его нет, добавь туда, это одна строка.

## Устройство

1. `src/parser.js` разбирает файл песни и проверяет ошибки.
2. `src/player.js` плеер: планировщик ударов, анимация, карта песни.
3. `src/audio.js` синтез гитары и метронома, обход беззвучного режима на iPhone.
4. `src/chords.js` аппликатуры и рисование диаграмм.
5. `src/main.js` маршруты: главная, страница песни, редактор.

Ритм ставится в очередь Web Audio заранее, на 120 мс вперёд, поэтому не плывёт, даже если страница подтормаживает. При сворачивании вкладки плеер встаёт на паузу.

## Об авторских правах

В проекте хранятся только аккорды, структура и темп. Тексты песен не хранятся и добавлять их не надо: они защищены авторским правом.
